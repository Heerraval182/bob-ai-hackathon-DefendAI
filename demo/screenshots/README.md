# Screenshots

Place application screenshots in this folder to demonstrate the Mission Readiness & Predictive Maintenance Copilot running with realistic data.

## Naming Convention

Name screenshots sequentially so they appear in logical order:

```
01-fleet-readiness-dashboard.png   ← Fleet-wide readiness overview with status badges
02-equipment-health-detail.png     ← Individual asset health page with sensor trends
03-active-alerts.png               ← Alert list with failure probability and predicted date
04-maintenance-recommendations.png ← Prioritised maintenance task list
05-copilot-chat.png                ← Natural-language Copilot answering a readiness question
```

## Requirements

- Minimum: 3 screenshots
- Format: PNG or JPG
- Show the application running with simulated HUMS data (not empty states)
- Avoid screenshots with placeholder or lorem-ipsum text

## Tips

- Use a consistent browser window size across all screenshots
- Highlight key UI elements (readiness badge, risk score, Copilot response) with arrows or circles if helpful
- Include at least one screenshot showing the IBM Bob Copilot integration in action
