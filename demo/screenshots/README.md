# Screenshots

Place application screenshots in this folder to demonstrate the Mission Readiness & Predictive Maintenance Copilot running with realistic data.

## Naming Convention

Name screenshots sequentially so they appear in logical order:

```
01-fleet-readiness-dashboard.png   ← Fleet-wide readiness overview with MISSION READY / WARNING / NOT READY badges
02-equipment-health-detail.png     ← Individual asset health page with sensor trend charts (temp, vibration, pressure)
03-active-alerts.png               ← Alert list with failure probability, risk level, and predicted RUL
04-maintenance-recommendations.png ← Prioritised maintenance task list (Critical → High → Medium → Low)
05-copilot-chat.png                ← Natural-language Copilot answering a readiness or maintenance question
```

## Requirements

- Minimum: 3 screenshots
- Format: PNG or JPG
- Show the application running with seeded HUMS data (not empty states)
- Avoid screenshots with placeholder or lorem-ipsum text

## Tips

- Use a consistent browser window size (1280×800 or wider) across all screenshots
- Highlight key UI elements (readiness badge, XGBoost risk score, RUL estimate, Copilot response) with arrows or circles if helpful
- Include at least one screenshot showing the IBM Bob Copilot integration in action
- If both `MISSION READY` and `NOT MISSION READY` assets are visible in the same view, that clearly demonstrates the system working
